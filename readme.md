# Scanner

A fast, unbranded QR code and barcode scanner/generator for Android built natively with **Kotlin** and **Jetpack Compose** — zero ads, zero tracking, zero bloat.

## Core Features
- **Live CameraX Scanning:** Tap-to-focus with reticle-cropped ML Kit barcode detection.
- **QR Generator:** Instant ZXing QR creation with one-tap PNG sharing.
- **Offline History:** Room database saving up to 100 scans locally with auto-pruning.
- **Quick Settings Tile:** Native `Scan QR` Control Center applet for instant camera launch.
- **Radial Navigation Hub:** One-handed bottom-right edge thumb menu.
- **Pure AMOLED Black:** Material 3 theming with true `#000000` black mode and splash screen.

## Stack
- **Language:** Kotlin 2.2 & Jetpack Compose (Material 3)
- **Vision & QR:** CameraX 1.5, ML Kit Barcode Scanning, ZXing Core
- **Storage:** Room Database with KSP

## Install
Download the latest **`app-release.apk`** from the **[Releases](../../releases)** tab on the right and install it on your Android device.
